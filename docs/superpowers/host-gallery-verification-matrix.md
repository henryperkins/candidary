# Host Gallery Roadmap — Verification Matrix

**Program:** [Host Gallery Roadmap](specs/2026-08-23-host-gallery-roadmap-program-design.md)

Every finding from the [Combined Host Gallery Experience Review](../../gallery-host-combined-review.md)
appears here exactly once, with one of four dispositions:

- `verified-existing` — current code already satisfies the finding, and a regression proves it;
- `implemented` — this roadmap changed code and the regression passes;
- `deferred-approved` — cross-audience withdrawal only;
- `out-of-scope-approved` — broader ownerless recovery only.

A row is complete only when its owning test file names a real test that fails without the change.
Slices 2–6 fill their own sections as they land; this file is the program's single record.

### Named expansions

The spec forbids broad phrases standing in for coverage. The two that slice 1 uses expand to these
exact lists.

**Every ordinary media query that must exclude a trashed row.** Each has a fixture proving the row
would otherwise appear:

| Surface | Query |
| --- | --- |
| Manager Intake (active) | `buildManagerMediaQuery` |
| Library / private Gallery | `MediaRepository.listGalleryTimeline` (including its search branch) |
| Album picks | `albumPickQuery` (retained picks resolve to opaque markers, never to photos) |
| Public and Preview Album | `PublicAlbumService.project` |
| Guest gallery | `MediaRepository.listGallery` |
| Guest's own contributions | `MediaRepository.listContributions` |
| Guestbook caption feed, Manager projection, caption item, export snapshot | `worker/db/guestbook.ts` (four sites) |
| Preview and original delivery | `worker/routes/content.ts` (two sites) |
| Export creation, both kinds | `eligibleSourceSql` in `worker/db/exports.ts` |
| Publication writes | `setPublication`, `setPublicationBulk` |
| Favorite writes and album capacity | `setFavorite`, `setFavoriteBulk`, `addFavoritesWithinAlbumCapacity` |
| Timeline maintenance | `countStoredTimelineSentinels`, `repairStoredTimelineSentinels` |
| Legacy preview pointer | `setPreviewObjectKey` |

The only paths permitted to read a trashed row are `listTrashed`, `listExpiredTrashed`,
`restoreTrashed`, `permanentlyDeleteTrashed`, the guest self-delete transition, the purge
terminalization, and the Manager Album retained-slot resolver.

**Every destructive action that must be confirmed before a request is sent.** Slice 1 adds two, and
each is asserted by "no request precedes the confirmation", initial focus on the nondestructive
control, Escape and cancel sending nothing, and exactly one request on explicit activation:

| Action | Surface |
| --- | --- |
| Move a photo to Recently deleted | Manager Intake |
| Stop the Album link | Manager Album sharing |
